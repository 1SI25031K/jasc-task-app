# JASC タスクマネージャー UIデザイン仕様書（Google アカウント管理風 / フェーズ 7.6-R）

本仕様書は、Google アカウント管理画面風の統一レイアウトへの全面刷新（フェーズ 7.6-R）におけるデザイン規約、Streamlit での実現方法、および検証チェックリストを定義するものです。

---

## 1. デザイン仕様

### 【色（Colors）】
- **ページの背景**：`#F0F4F9`（サイドバーも完全に同一色とし、境目の線や境界の影は一切付けない）
- **カード**：`#FFFFFF`、角丸 `28px`、枠線なし（border: none）、影なし（box-shadow: none）
- **メイン色（primary）**：`#0B57D0`（`.streamlit/config.toml` の `primaryColor` も本値に統一）
  > [!IMPORTANT]
  > **赤色（#B3261E 系）は、システムエラーメッセージおよび「期限を過ぎた NA（件数等）」の警告表示にのみ限定して使用し、ボタンや通常UIパーツには一切使用しない。**
- **選択中のナビゲーション項目背景**：`#D3E3FD`
- **文字色**：
  - 本文テキスト：`#1F1F1F`
  - 補助テキスト（キャプション・サブタイトル）：`#444746`
  - 区切り線（Divider）：`#C4C7C5`
- **ナビゲーションのアイコン丸（背景色／アイコン色）のトナルパレット（全6色組）**：
  1. 青（Blue）：`#D3E3FD` ／ `#0B57D0`
  2. 紫（Purple）：`#E9DDFF` ／ `#6B4FBB`
  3. 緑（Green）：`#C4EED0` ／ `#146C2E`
  4. オレンジ（Orange）：`#FFDCC1` ／ `#8B4A00`
  5. ピンク（Pink）：`#FFD8E4` ／ `#9C2A5C`
  6. ティール（Teal）：`#BDEBEA` ／ `#00696B`
  ※隣接する項目同士が同じ色にならないよう交互に割り当てを行う。
- **選択中項目のアイコン丸**：背景は塗りつぶし `#0B57D0`、アイコン色は白 `#FFFFFF`。

### 【上部バー（Top Bar）】
- **バー全体仕様**：高さ `64px`、背景色はページ全体と同一の `#F0F4F9`、下部の境界線なし。
- **左側コンテンツ**：アプリ名「`JASC タスクマネージャー`」（Google Sans Flex、`22px`、font-weight `400`、文字色 `#1F1F1F`）。
- **右側コンテンツ**：
  - ヘルプアイコン（`24px`、`:material/help_outline:`）
  - 背景設定用プレースホルダー（フェーズ 7.7 用のスペーサー）
  - ユーザーアバター（直径 `40px` の丸、Google アカウント画像または名前頭文字）
- **アバター操作（ポップオーバー）**：
  - アバターを押すと `st.popover` が開き、「氏名」「メールアドレス」「表示言語切替（日本語／English）」「ログアウト」を表示。
  - **サイドバーにあるログイン情報・メールアドレス・言語切替・ログアウト・アプリ名は、すべてここへ移設し、サイドバーからは完全削除する。**
- **Streamlit 標準ヘッダー**：
  - 利用者に不要な標準ツールバーやメニュー（Deploy ボタン、Running インジケータ、オプションメニュー）は完全非表示化。

### 【左のナビゲーション（Sidebar Navigation）】
- **領域仕様**：幅 `280px`、背景 `#F0F4F9`（境界線・右枠線・影なし）。
- **各ナビゲーション項目**：
  - 高さ `56px`。
  - 構造（左から）：直径 `40px` の丸アイコン（内部アイコン `24px`） ＋ `16px` の間隔 ＋ 項目名（Google Sans Flex、`16px`、font-weight `400`）。
- **選択中の項目**：項目全体がピル型（角丸 `28px`）、背景 `#D3E3FD`、項目名 font-weight `500`、アイコン丸は塗りつぶし `#0B57D0`＋白アイコン。
- **ホバー時**：薄いグレー背景（`#E1E5EA`）へ滑らかに変化。
- **項目の配置順（全10画面）**：
  1. ホーム (`pages/home.py`)
  2. 役職ボード (`pages/board.py`)
  3. マイタスク (`pages/my_tasks.py`)
  4. 依頼の受信箱 (`pages/inbox.py`)
  5. 期限アラート (`pages/alerts.py`)
  6. 全タスク (`pages/all_tasks.py`)
  7. 余力マップ (`pages/capacity_map.py`)
  8. 体感負荷を回答 (`pages/checkin.py`)
  9. NA 生成 (`pages/minutes.py`)
  10. 進捗 (`pages/progress.py`)
  ※「役職詳細 (`pages/role_detail.py`)」はナビゲーション項目から除外し、役職ボード内のカードから開く専用画面とする。
- **「新しいタスクを作成」ボタン**：サイドバーから削除し、各画面の右上（またはフローティング）に配置。
- **サイドバー最下部**：`14px` 補助色（`#444746`）で「使い方・ヘルプ・このアプリについて」のリンクを静かに配置。
- **スマホ幅レスポンシブ**：ナビゲーションは標準で折りたたまれ、上部バー左側のメニューアイコン（ハンバーガーボタン）から開閉可能。

### 【ページ本文（Page Content）】
- **レイアウト幅**：本文コンテナの最大幅を約 `960px` に制限し、画面中央に配置（横いっぱいに広げない）。
- **見出し（Heading）**：
  - アイコンなし。
  - Google Sans Flex、`32px`、font-weight `400`、文字色 `#1F1F1F`。
- **説明文（Subtitle）**：`14px`、補助色 `#444746`、最大1行まで。
- **役職ボードのカード**：
  - 役職名：`22px`、font-weight `400`。
  - 責任者表示：`14px`、補助色 `#444746`。
  - 件数サマリー：色付き角丸バッジを廃止し、「`未完了 2 · 期限切れ 1 · 今週 1`」の 1 行テキスト（「期限切れ」の件数のみ赤色 `#B3261E`）。
  - 最も期限の近い NA：1行表示（長い場合は CSS または Python 側で `...` 省略）。
  - 詳細リンク：幅いっぱいのボタンを廃止し、カード右下に控えめなテキストボタン（「役職詳細 →」）を配置、またはカード全体をクリック可能化。
- **タブ（st.tabs）**：選択中の下線インジケータおよび文字色を `#0B57D0` に統一。
- **ボタン（Buttons）**：
  - 主要操作（Primary）：塗りつぶしピル型（背景 `#0B57D0`、文字白、高さ `40px`、左右余白 `24px`、角丸 `20px`）。
  - 補助操作（Secondary）：テキストボタン（背景透明、枠線なし、文字色 `#0B57D0`、ホバー時淡い青背景）。
  - **全画面を通じて「幅いっぱいのボタン（use_container_width=True）」は原則使用しない。**

### 【ホーム（あいさつ画面）】

## 2. Streamlit での実現方法と技術方針

| デザイン要件 | Streamlit 標準機能での可否 | 実現方法（該当コード・CSS設計） | 備考・代替案 |
| :--- | :--- | :--- | :--- |
| **背景色の一致と境界線の除去** | △ 一部可能・CSS補完必須 | 1. `.streamlit/config.toml` で `backgroundColor = "#F0F4F9"`、`primaryColor = "#0B57D0"` を指定。<br>2. `core/ui/style.py` で `section[data-testid="stSidebar"] { background-color: #F0F4F9 !important; border-right: none !important; box-shadow: none !important; }` を適用。 | サイドバーとメインエリアの境界ボーダーを完全除去。 |
| **カード（白、角丸 28px、枠線なし、影なし）** | △ CSS補完必須 | `st.container(border=True)` を使用し、CSS で `div[data-testid="stVerticalBlockBorderWrapper"] { background-color: #FFFFFF !important; border-radius: 28px !important; border: none !important; box-shadow: none !important; padding: 24px !important; }` を適用。 | `border=True` の枠線を CSS で `none` にし、白背景と角丸 28px を付与。 |

## 3. 実装の安全・セキュリティ規約（S6・agent_rules 遵守）

1. **静的 CSS の集約**：
   - すべての CSS ルールは `core/ui/style.py` に集約し、各ページでのインラインスタイル直書きを最小化する。
2. **S6 ユーザー入力／AI 出力の HTML 埋め込み禁止**：
   - ユーザー名・メールアドレス・タスク名・役職名など、動的なデータはすべて Streamlit 標準のウィジェット（`st.write`, `st.caption`, `st.button`, `st.radio` 等）で表示する。
   - アイコン丸やピル形状の装飾は CSS クラスおよび疑似要素のみで実現し、HTML 側へのデータ埋め込みは行わない。
3. **Google ロゴの厳格管理**：
   - Google の「G」ロゴはログイン画面（`core/ui/google_signin.py`）のみで使用し、ログイン後の通常画面では Google ロゴは使用しない（Google Sans Flex フォントおよび配色システムのみを適用）。

## 5. フェーズ 7.7 仕様（AI感の排除・最上部ピンクプログレスバー・背景設定）

### 【作業1（7.7-A）：AI感の排除（Google アカウント管理風の徹底）】
1. **文言の短縮・事実化**：
   - 「！」や「〜できます」「〜しましょう」「1クリックで回答できます」等の口語・誇張・過度な会話文を完全撤廃。
   - 見出し・説明文は事実のみを1行（最大）で簡潔に記述。
   - `locales/ja.toml` と `locales/en.toml` の両方を更新し、対応表を `docs/ui_copy_changes.md` に記録。
2. **カード連打から区切り線リストへの転換**：
   - 各タスクを個別の枠線付きカードで囲むのを廃止し、Google アカウント画面のように境界線 `#C4C7C5`（1px solid）で区切られた連続リスト（Expander）へ統一。
   - 行全体をクリック可能とし、開くとクイック更新フォームと詳細編集・変更履歴をタブ（`tab_quick` / `tab_full`）で表示（入れ子 Expander の完全全廃）。
3. **絵文字・装飾アイコンの全廃**：
   - 見出し・ボタン・ラベル内の絵文字（📌, 👥, 📊, 👆, ✉️, 💬, ✨, 😊, 😟 等）を全廃。
   - 色付きアイコンは左ナビゲーションとホームのお知らせカードのみに限定し、その他は補助色（`#444746`）の単色アイコンに統一。
4. **赤色（#B3261E）の厳格制限**：
   - システムエラーおよび「期限を過ぎた NA（期限超過バッジ・件数）」にのみ限定して赤色を使用。通常のステータスバッジはすべてニュートラルグレー（`:gray-badge[...]`）に統一。
5. **NA 生成の注意書き**：
   - 「AI が候補を作ります。内容を確認してから登録してください」（英語：「AI generates candidate next actions. Review before saving.」）の 1 行注記を配置。

### 【作業2（7.7-B）：最上部ピンク Linear Progress Indicator（不確定型）】
1. **位置・形状**：
   - ブラウザ最上部（`top: 0; left: 0; right: 0; position: fixed; z-index: 99999999;`）、高さ `4px`。
   - トラック背景色：`#FFD8E4`、インジケーター色：`#E8467C`（M3 Pink）。
2. **実行状態検知**：
   - CSS `:has()` 疑似クラス（`body:has([data-testid="stStatusWidget"])`）を使用し、JavaScript・ポーリングなしの純粋な CSS で実行状態を検知。
3. **Streamlit 標準アイコンの統合**：
   - 右上の標準処理中アイコン（Running Man・スピナー）は `visibility: hidden !important;` で非表示化し、最上部ピンクバーに一本化。
4. **アクセシビリティ対応**：
   - `prefers-reduced-motion: reduce` ではアニメーションを停止し、静止した幅 100% の 4px バーを表示。

### 【作業3（7.7-C）：背景の設定（新機能）】
1. **配置・トリガー**：
   - 上部バー右側、ユーザーアバターの左隣に Material Symbols の `wallpaper`（24px、`#444746`）アイコンボタンを配置。
2. **ポップオーバー構成**：
   - 見出し：「背景」（英語 UI：「Background」）。
   - 9色のカラーサークル（直径 32px、角丸 50%）：標準 `#F0F4F9`（既定）、ブルー `#E8F0FE`、ティール `#E0F2F1`、グリーン `#E6F4EA`、イエロー `#FEF7E0`、オレンジ `#FEEFE3`、ピンク `#FCE8F0`、パープル `#F3E8FD`、グレー `#F1F3F4`。
   - 選択中の色には青色輪（`outline: 2px solid #0B57D0; outline-offset: 2px;`）とチェックマークを表示。
