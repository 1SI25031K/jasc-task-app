# JASC タスクマネージャー Material 3 (M3) UI 仕様書

本仕様書は、「JASC EC ダッシュボード 移行仕様書」および `docs/requirements.md`・`docs/ui_spec.md` に基づき、Next.js 版の全画面を Google アカウント管理画面（myaccount.google.com）のような **Material 3（M3）純正デザインシステム** へ刷新するための仕様書です。

> **デザイン原則**:
> 1. 機能・データ・セキュリティの挙動は一切変更せず、**見た目（ビジュアル）・配置（レイアウト）・操作感（インタラクション）のみを M3 に完全準拠** させる。
> 2. `@material/web` はメンテナンスモードのため採用せず、M3 のデザイントークン（CSS 変数）と Tailwind CSS のカスタム設定を組み合わせた自前コンポーネントで構築する。
> 3. AI 特有の汎用 UI（グラデーション、発光シャドウ、過度な太字見出し、不要な枠線、冗長な口語文）を完全排除し、Google 公式製品の簡潔で洗練されたトーン＆マナーを実現する。

## 1. M3 デザイントークン仕様

### 1.1 カラーシステム（M3 トナルパレット準拠）

Google の Material Theme Builder に基づき、プライマリカラー `#0B57D0`（Google Blue）を起点としたカラーロールを CSS 変数として定義します。Tailwind からはこれらのセマンティックカラー名のみを使用し、Tailwind 既定の色（`blue-600`, `slate-100` 等）は使用しません。

| トークン名 (CSS 変数) | カラーコード | 用途・役割 |
|---|---|---|
| `--md-sys-color-primary` | `#0B57D0` | 主要な操作ボタン（Filled Button）、選択中アイコン、リンク |
| `--md-sys-color-on-primary` | `#FFFFFF` | Primary 背景上の文字・アイコン色 |
| `--md-sys-color-primary-container` | `#D3E3FD` | 強調コンテナ、FAB、選択中インジケータ |
| `--md-sys-color-on-primary-container` | `#041E49` | Primary Container 上の濃色文字 |
| `--md-sys-color-secondary` | `#475D92` | 補助的なアクション、フィルター |
| `--md-sys-color-on-secondary` | `#FFFFFF` | Secondary 背景上の文字 |
| `--md-sys-color-secondary-container` | `#D8E2FF` | ナビゲーション選択項目のピル背景（`#D3E3FD` 統合） |
| `--md-sys-color-on-secondary-container` | `#001A41` | ナビゲーション選択項目の文字色 |
| `--md-sys-color-surface` | `#F0F4F9` | **アプリ全体の背景色**（上部バー・サイドバー・メイン領域統一） |
| `--md-sys-color-surface-dim` | `#D9DFE6` | 控えめなサーフェス |
| `--md-sys-color-surface-bright` | `#F8F9FA` | 明るいサーフェス |
| `--md-sys-color-surface-container-lowest` | `#FFFFFF` | **カード・一覧リストの背景色**（純白で浮かび上がらせる） |
| `--md-sys-color-surface-container-low` | `#F0F4F9` | 階層の低いコンテナ |
| `--md-sys-color-surface-container` | `#E9EEF6` | 入力欄（Filled Text Field）の背景色 |

#### ■ ナビゲーション丸アイコン用 トナルパレット（全6色組・交互配色）
左ナビゲーションの各項目に配置される直径 40px の円形アイコン背景です。
1. **青（Blue）**: 背景 `#D3E3FD` ／ アイコン `#0B57D0`
2. **紫（Purple）**: 背景 `#E9DDFF` ／ アイコン `#6B4FBB`

### 1.2 タイポグラフィ（Google Sans Flex ＆ Noto Sans JP）

フォントファミリーは Google Sans Flex（英数字フォント、フォールバック: Roboto / Inter / -apple-system）および Noto Sans JP（日本語）を採用します。
**太すぎる見出し（font-weight 700 以上）を撲滅し、400〜500 に抑える** ことで、Google アカウント管理画面特有の落ち着いた視覚的品位を再現します。

| M3 タイプスケール | サイズ / 行送り | Weight | 主な適用箇所 |
|---|---|---|---|
| **Headline Large** | `32px / 40px` | `400` | ホーム画面の「おはようございます」等の主あいさつ |
| **Headline Medium** | `28px / 36px` | `400` | 各画面の大見出し（役職ボード、マイタスクなど） |
| **Headline Small** | `24px / 32px` | `400` | セクション見出し、モーダルタイトル |
| **Title Large** | `22px / 28px` | `400` | **上部バーのアプリ名「JASC タスクマネージャー」** |
| **Title Medium** | `16px / 24px` | `500` | タスク名、役職カード見出し、ナビゲーション選択項目 |
| **Title Small** | `14px / 20px` | `500` | サブセクション見出し、タブ項目名 |
| **Body Large** | `16px / 24px` | `400` | 本文、ナビゲーション非選択項目名 |
| **Body Medium** | `14px / 20px` | `400` | タスク詳細、次のアクション (NA)、説明文 |
| **Body Small** | `12px / 16px` | `400` | 補足情報、更新日時、担当者負荷表記 |
| **Label Large** | `14px / 20px` | `500` | Filled Button、Outlined Button のテキスト |
| **Label Medium** | `12px / 16px` | `500` | フィルターチップ、Assist Chip、ステータスラベル |
| **Label Small** | `11px / 16px` | `500` | M3 Badge（件数バッジ）、極小キャプション |

### 1.3 アイコン（Material Symbols Rounded 統一）

`lucide-react` を完全撤廃し、Google 公式の **Material Symbols Rounded**（可変フォント）を導入します。

- 読み込み: `<link rel="stylesheet" href="https://fonts.googleapis.com/css2?family=Material+Symbols+Rounded:opsz,wght,FILL,GRAD@20..48,100..700,0..1,-50..200" />`
- 既定値: `FILL 0`（アウトライン型、選択時は `FILL 1`）、`wght 400`、`GRAD 0`、`opsz 24`。
- クラス名: `.material-symbols-rounded`

### 1.4 シェイプ（角丸・サイズ・ステートレイヤー）

| シェイプ種別 | 半径 | 主な適用部品 |
|---|---|---|
| **None** | `0px` | ページ背景、境界なし分割エリア |
| **Extra Small** | `4px` | テキストフィールドのアクティブインジケータ |
| **Small** | `8px` | ツールチップ、ドロップダウンメニューの角丸 |
| **Medium** | `12px` | 1〜10 チェックインボタン、インラインカード |
| **Large** | `16px` | Navigation Rail のアクティブインジケータ |
| **Extra Large** | `28px` | **ホワイトカード、モーダルダイアログ、Navigation Drawer 選択ピル** |
| **Full** | `9999px` | **ボタン（Filled / Outlined / Text）、ピル型検索バー、Assist Chip、バッジ** |

- **ステートレイヤー（State Layer）**:
  - Hover: 対象色の上から `opacity: 0.08` のオーバーレイ
  - Focus: `outline: 2px solid var(--md-sys-color-primary); outline-offset: 2px;`
  - Pressed: `opacity: 0.12` のオーバーレイ

### 2.1 上部バー（Top App Bar）
- **仕様**: 高さ `64px`、背景はページと完全に同一の `--md-sys-color-surface`（`#F0F4F9`）、境界線なし。
- **左側**:
  - モバイル / タブレット時のみ: ハンバーガーメニューボタン（`menu` アイコン、48x48px タッチターゲット）。
  - アプリ名: 「`JASC タスクマネージャー`」（Title Large 22px 400、文字色 `#1F1F1F`）。
- **右側**:
  - ヘルプアイコンボタン（`help`、24px、`#444746`）。押すと各画面の使い方ガイドダイアログを表示。
  - 背景設定アイコンボタン（`wallpaper`、24px、`#444746`）。押すと背景色パレット・Bing「今日の景色」ポップオーバーを表示。
  - ユーザーアバターボタン（直径 40px）。押すと M3 Menu（氏名、メールアドレス、言語切替 ja/en、ログアウト）を表示。
  - **※「タスクを作成」ボタンは上部バーから削除**（M3 原則に従い、画面内プライマリアクションまたは FAB に移行）。

### 2.2 左ナビゲーション（3段階レスポンシブ）
1. **PC 幅（>= 1240px: Standard Navigation Drawer）**:
   - 幅 `280px`、ページ背景と同一の `#F0F4F9`。
   - 項目高 `56px`。直径 40px の色付き丸アイコン ＋ 項目名。
   - 選択項目は角丸 `28px` のピル形状（背景 `#D3E3FD`、丸アイコンは青塗りつぶし `#0B57D0` ＋ 白アイコン）。
   - 件数バッジ（受信箱の未対応件数、期限アラート件数）は右端に M3 Badge で配置。
2. **タブレット幅（840px 〜 1239px: Navigation Rail）**:
   - 幅 `80px` のスリムな縦型バー。
   - アイコン中心の配置。選択中はピル型インジケータ（高さ 32px、幅 56px、角丸 16px）。
3. **スマホ幅（< 840px: Modal Navigation Drawer）**:
   - 初期状態は非表示。上部バーのメニューボタン（`menu`）を押すと左からスライドイン。
   - 背景に `rgba(0, 0, 0, 0.4)` のオーバーレイを表示。

### 2.3 フローティングアクションボタン（M3 FAB）
- 画面右下に固定配置される「＋ タスクを作成」ボタン（M3 Extended FAB または Standard FAB）。
- 角丸 `16px`、背景 `--md-sys-color-primary-container`（`#D3E3FD`）、文字・アイコン `--md-sys-color-on-primary-container`（`#041E49`）。
- スクロール時も押しやすい位置に常駐し、どの画面からでもワンタップでタスク作成モーダルを起動可能。

### 4.3 タスク一覧画面（M3 List 構造：マイタスク・全タスク・役職詳細共通）

カードの多重枠線を廃止し、Google アカウント管理画面のように **1px の境界線（`--md-sys-color-outline-variant`）で区切られた行リスト** とします。行全体をクリックするとインライン展開し、クイック更新フォームと詳細編集・変更履歴をスムーズに操作できます。

```
+---------------------------------------------------------------------------------------------------+
|  [ ✓ ]  文科省への後援申請書の送付                                                 2026-11-10 (明日) |
|         NA: 申請書類一式を印刷し、押印のうえ郵送手続きを行う。      担当: 宮本  役職: 実行委員長     |
```

## 5. 発見された不具合の修正仕様

### 5.1 体感負荷チェックインの状態非同期バグ
- **現象**: 「体感負荷 7 を記録しました」と成功メッセージが出るものの、ボタングリッドの「回答済」表示やステータスカード（`あなたの現在のステータス`）が前回のスコア（例: 6）のまま更新されない。
- **原因の特定**:
  1. `src/context/DashboardContext.tsx` 内の `DashboardProvider` が `const [data, setData] = useState(initialData);` で初期化されているが、サーバー側の `revalidatePath` および `router.refresh()` 実行後に `initialData` プロパティが更新されても、`data` ステートに反映する `useEffect` が存在しない。
  2. このため、ブラウザのリロード（F5）を行うまでクライアント側の `data.checkins` が更新前の古い状態を保持し続けていた。
- **修正内容**:
  1. `DashboardContext.tsx` に `useEffect(() => { setData(initialData); }, [initialData]);` を追加し、サーバーデータの再検証結果をクライアントステートへ即座に同期する。
  2. `checkin/page.tsx` において、`saveCheckinAction` 成功時にローカルステート（`latestCheckin`）を直ちに返却スコアで楽観更新し、ネットワーク遅延に関係なく即座にボタン・ステータス表示が切り替わるようにする。

### 5.2 目盛り説明の二重表記バグ
- **現象**: 1〜10 ボタングリッドの両端ラベルが「1: 1〜4：余裕あり」「10: 8〜10：高負荷」と数字が二重に表示される。
- **原因**: 画面側で `1: {t("checkin.group_low")}` と記述しており、辞書側のキー `checkin.group_low` に「1〜4：余裕あり」という数字プレフィックスが含まれていたため。
- **修正内容**:
  - ラベル描画を簡潔に `t("checkin.group_low")` および `t("checkin.group_high")` の直接表示に改め、「余裕あり」「高負荷」の事実のみをすっきりと配置する。
