# ホスティング先の選定と比較（docs/hosting.md）

「JASC EC ダッシュボード 移行仕様書（Python → TypeScript / Next.js）」§7 に基づき、新ダッシュボード（Next.js App Router）のホスティング先の候補と判断材料を整理しました。

---

## 1. 比較サマリー

| 候補 | コスト（15名利用時） | 利用規約（団体利用） | Next.js 適合性 | アカウント管理 | 推奨度 |
|---|---|---|---|---|---|
| **A. Vercel (Hobby)** | 無料 | ⚠️ **グレー**（個人・非商用に限定） | ◎ 完璧（開発元） | GitHub / Google 共有垢可 | ◯（規約容認なら最速） |
| **B. Google Cloud Run** | 無料（無料枠内） | ◎ 問題なし | ◎ 完璧（Docker / Node.js完全準拠） | JASC GCP に統合可能 | **◎ 第1推奨（最適）** |
| **C. Cloudflare Pages** | 無料 | ◎ 問題なし | △ やや設定要（OpenNext / Edge） | 共有垢可、Zero Trust無料 | ◯（認証不要化の強み） |
| **D. Render / Railway** | 有料（月$5〜7）<br>※無料枠はスリープあり | ◎ 問題なし | ◯ 良好 | 共有垢可 | △ コスト発生 |

## 2. 各候補の詳細評価

### 候補 A: Vercel（Hobby プラン）
Next.js の開発元であり、最も簡単に高速なデプロイとサーバーサイドキャッシュ（`revalidate`、`unstable_cache`）を実現できます。

- **利用規約・ライセンス**:
  - Hobby プランの Terms of Service では「Personal, non-commercial projects only」と明記されています。
  - 学生団体の非営利・学術的活動が「Personal」に含まれるかは解釈が分かれるグレーゾーンです。万が一の利用停止リスクを嫌う組織では敬遠されることがあります（組織向け Pro プランは $20/月/seat）。
- **無料枠の範囲**:
  - 月 100GB 帯域、Edge Middleware 100万回実行。15 名の EC ダッシュボード利用であれば無料枠を大幅に下回ります。
- **Next.js 対応状況**:
  - 公式のため 100% の機能（App Router、Server Actions、Streaming、Tag ベースの Cache Revalidation）が設定不要で動作します。
- **環境変数の管理**:
  - Web ダッシュボード上で暗号化管理（Production / Preview / Development 分離）。
- **アカウント名義**:
  - GitHub または Google アカウントで作成可能。JASC 共有アカウントでの作成が可能です。

---

### 候補 B: Google Cloud Run（★第1推奨）
JASC はすでに Google スプレッドシートや GCP サービスアカウントを利用しているため、既存の Google Cloud 環境に統合できる最も堅牢な選択肢です。

- **利用規約・ライセンス**:
  - 商用・非商用・法人・団体を問わず利用可能。学生団体の公式業務ツールとして規約上の懸念が一切ありません。
- **無料枠の範囲（毎月永久無料）**:
  - 毎月 200万リクエスト、360,000 vCPU秒、180,000 GiB秒メモリ、1GB 下り転送。
  - 15名が毎日アクセスしても月数千〜数万リクエスト程度であり、**完全無料枠内（0円）**で運用できます。
- **Next.js 対応状況**:
  - 公式の `output: 'standalone'` モードを用いた Docker コンテナとして実行。
  - Node.js のフル機能環境で動くため、`googleapis` ライブラリや Node 依存のキャッシュ機構、App Router が制限なく 100% 安定動作します。
- **セキュリティ・環境変数**:
  - Secret Manager または Cloud Run の環境変数でセキュアに管理。
  - さらに、Cloud Run の実行サービスアカウントに直接権限を付与できるため、**コードや環境変数にサービスアカウント秘密鍵 JSON を持たせる必要すらなくなり、漏洩リスクを根本から排除**できます。
- **コールドスタート**:
  - アクセスがない時はインスタンスが 0 にスケールダウンします。コールドスタートからの復帰は約 2〜3 秒（Streamlit の 30秒〜1分スリープに比べると極めて高速）。
  - ※なお、Google Cloud の無料枠利用にはクレジットカードの登録（請求先アカウント）が必要です。

---

### 候補 C: Cloudflare Pages / Workers ＋ Cloudflare Zero Trust
世界最速レベルのエッジネットワークと、強力な無料枠を誇ります。

- **利用規約・ライセンス**:
  - 無料プランでも団体の利用規約違反はありません。
- **無料枠の範囲**:
  - 1日 100,000 リクエスト無料、帯域幅は完全無制限・無料。15名の利用では全く問題ありません。
- **Next.js 対応状況**:
  - `@opennextjs/cloudflare` または `@cloudflare/next-on-pages` を使用。
  - Node.js 環境ではなく V8 Edge ランタイムで動くため、Node.js 固有のモジュール（一部の暗号化やファイルシステム操作）や `googleapis` の動作に互換レイヤーや polyfill が必要になる場合があります。
- **追加メリット（Cloudflare Zero Trust / Access）**:
  - 最大 50 ユーザーまで無料で Cloudflare Access（ゼロトラスト SSO）が利用できます。
  - アプリ側に Google OAuth コードを書かなくても、Cloudflare の手前で「@xxx.org の Google ログインに制限する」設定が可能になります。

---

### 候補 D: Render / Railway
PaaS として人気のサービスですが、無料運用の観点からは課題があります。

- **Render**: 無料 Web サービスは 15 分無アクセスでスリープし、復帰に 50 秒以上かかります（現行 Streamlit と同じ課題が残ります）。スリープをなくすには月額 $7（約1,100円）が必要です。
- **Railway**: 以前の無料枠は廃止され、月額従量課金（トライアル $5 のみ）となりました。

## 3. 推奨案と選定のポイント

### 【推奨案 1】Google Cloud Run（もっとも安心・安全）
- **理由**:
  1. すでに GCP を使っているため、管理アカウントを増やさず一本化できる。
  2. 規約のグレーゾーンがなく、翌年度以降の引継ぎでも安心。
  3. サービスアカウント鍵をファイルや環境変数で抱え込まず、IAM 権限だけでセキュアにスプレッドシートを読み取れる。
  4. 15 人規模であれば毎月の無料枠（0円）で余裕で収まる。

### 【推奨案 2】Vercel（手軽さ・開発速度を最優先する場合）
- **理由**:
  1. GitHub に Push するだけで自動ビルド・即時プレビューができる。
  2. Next.js 固有の最適化が最も自然に働く。
  3. ※「学生会議の非営利プロジェクト」として Hobby プランを利用することを許容できる場合に限る。
